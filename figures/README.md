# Figures

This folder contains selected figures from the Bachelor's Thesis project.

## Selected figures

- `venn_diagram.png`: Multi-wavelength classification of sources detected in optical, X-ray and far-infrared catalogues.
- `luminosity_redshift.png`: Relationship between X-ray luminosity and redshift for the analysed quasar samples.
- `redshift_comparision.png`: Comparison of redshift distributions across different detection regions.
- `xray_luminosity_histogram.png`: Distribution of X-ray luminosity for the X-ray-detected subsamples.
- `fir_flux_distribution.png`: Far-infrared flux distribution at 250 microns.

The figures are selected from the Bachelor's Thesis report and summarize the main visual results of the analysis.
